Engine-connected timeline: behaviour tests

Runs the real axLiveHeartRate script from index.html inside a tiny in-page DOM stub with a controllable fetch. No engine is contacted: every request the page script makes is captured and answered by the test. Serve this folder (for example python3 -m http.server 3000) and open http://localhost:3000/tests/timeline_confidence.test.html. Results are also logged to the console and exposed as window.__results. All sample data is fictional.
